
# TERANG — Lapor. Kawal. Tuntas.

TERANG adalah platform digital untuk membantu masyarakat melaporkan, memantau, dan mengawal perbaikan infrastruktur publik secara transparan dan partisipatif.

## Permasalahan

Pelaporan kerusakan fasilitas publik sering kali belum memberikan informasi yang jelas mengenai proses verifikasi, penentuan prioritas, dan perkembangan penanganan. Masyarakat juga membutuhkan cara untuk mengetahui apakah kerusakan yang telah diperbaiki muncul kembali.

## Fitur Utama yang Direncanakan

1. Form Lapor — Pelaporan kerusakan dengan foto dan lokasi.
2. Peta Laporan — Pemetaan kondisi infrastruktur.
3. Smart Priority — Pengelompokan prioritas penanganan.
4. Radar Rusak Lagi — Deteksi indikasi kerusakan berulang.
5. Deteksi Laporan Terkait — Pemeriksaan potensi laporan ganda.
6. Human Crosscheck — Verifikasi oleh petugas.
7. Jejak Keputusan — Riwayat keputusan dan perubahan status.
8. Jejak Anggaran — Informasi anggaran dengan sumber terverifikasi.
9. Dashboard Akuntabilitas — Pemantauan perkembangan laporan.

## Tech Stack

- React
- Vite
- JavaScript
- ESLint

## Cara Menjalankan

1. Clone repository:
   git clone https://github.com/allegrarethaa06/TERANG.git

2. Masuk ke folder project:
   cd TERANG/terang

3. Install dependency:
   npm install

4. Jalankan website:
   npm run dev
